# Project Vision & Constitution

> **AGENT INSTRUCTION:** Read this file before every iteration. It serves as the project's "Long-Term Memory."

## 1. Core Identity
* **Project Name:** WebCraft Studio – Webdesign Agentur für Gründer & Start-ups
* **Mission:** Hochkonvertierende, rechtssichere Websites für Gründer und Start-ups in Deutschland.
* **Target Audience:** Gründer und Start-ups in Deutschland (B2B, unter 3 Jahre alt, 0–20 Mitarbeiter).
* **Voice:** Direkt, vertrauenswürdig, kompetent, empathisch. Spricht die echten Ängste der Zielgruppe an.

## 2. Visual Language
* **The "Vibe":**
  * *Primary:* **Professionell** (Hellgrauer Hintergrund, klare Linien, viel Weißraum)
  * *Secondary:* **Vertrauenswürdig** (Business-Blau als Akzentfarbe, Serif-Überschriften)
  * *Tertiary:* **Modern** (Saubere sans-serif Fließtexte, subtile Animationen)
* **Color Philosophy:**
  * **Backgrounds:** Weiß (#FFFFFF) + Hellgrau (#F8FAFC)
  * **Primary Accent:** Business-Blau (#1E3A5F)
  * **Secondary Accent:** Hellblau (#3B82F6)
  * **Text Primary:** Dunkelgrau (#1F2937)
  * **Text Secondary:** Mittelgrau (#6B7280)
  * **Text Accent:** Gold/Amber (#F59E0B) für Trust-Badges

## 3. Architecture & File Structure
* **Root:** `webdesign-agentur/`
* **Framework:** React + Vite + Tailwind CSS
* **Navigation:** Nav → Hero → Pain → USP → Prozess → Referenzen → Testimonials → Preise → Kontakt → Footer
